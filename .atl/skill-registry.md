## Compact Rules

### Shopify Liquid Themes (shopify-liquid-themes)
**Trigger**: Creating/editing `.liquid` files, schema JSON, translation keys
- Use `{% render %}` — never `include` (deprecated)
- 2-space indentation, hyphenated Liquid tags `{%- -%}`
- snake_case variables, translation keys (`t:key.path`) for all labels
- Schema translations in `*.schema.json`, UI translations in `*.json`
- `for` loops max 50 iterations — use `{% paginate %}` for larger arrays
- No parentheses in conditions, no ternary — use nested `{% if %}`
- `{% stylesheet %}`/`{% javascript %}` don't render Liquid

### Liquid Theme Standards (liquid-theme-standards)
**Trigger**: Writing CSS, JS, or HTML patterns in `.liquid` files
- BEM naming inside `<style>` tags
- CSS custom properties for theming: `var(--color-primary)`
- Mobile-first: base styles mobile, `@media (min-width: 768px)` for desktop
- Container queries: `container-type: inline-size`
- One class per JS file, ES6 modules with `import`/`export`
- Native HTML elements first: `<details>`, `<dialog>`, `popover`, `<search>`
- Web Components with `connectedCallback`/`disconnectedCallback`
- AbortController for fetch, clean up event listeners

### Agent Browser (agent-browser)
**Trigger**: Testing, screenshots, filling forms, navigating sites
- Use for browser automation and E2E visual testing
